# Repo Notes

- This is a TypeScript ESM MCP server. In `src/`, keep relative imports using explicit `.ts` extensions; the build rewrites them for `build/`.
- This repo enforces LF line endings via `.gitattributes`. Preserve LF when editing files.
- Edit `src/` and tests, not `build/`. `build/` is generated by `npm run build`.
- Running the server requires `MARKDOWN_STORE_REPO` to point at the canonical markdown repo. Tests create their own temp repos, so `npm test` works without extra setup.
- Current MCP surface is intentionally small: `create_doc` and `get_doc`.
- After changes, run `npm run prettier:format`, `npm test`, and `npm run typecheck`. Run `npm run build` too when `src/` changes.
